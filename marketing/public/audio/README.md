# Musik & SFX

Taruh backsound di folder ini dengan nama:

- `music.mp3` — musik utama, akan di-loop sepanjang 40 detik.

Volume default di komposisi adalah `0.12` (agar tidak menutupi VO). Ubah di
`src/Video.tsx` kalau perlu.

## Lisensi

Gunakan musik yang jelas lisensinya untuk konten promosi, misalnya:

- Pixabay Music
- YouTube Audio Library
- Uppbeat (cek lisensi plan gratis)
- Epidemic Sound (berbayar)

Jangan memakai lagu populer/commercial tanpa izin, walau hanya 40 detik.
